design system · one stylesheet, seven pages

The parts these pages are made of

The six demo pages were written one at a time, and each carried its own copy of the same hundred lines of CSS. The copies drifted — four paddings for one button, four measures for one paragraph, three gaps above a section — so the pages looked related rather than identical. Everything shared now lives in design-system.css: tokens first, then primitives built from them. This page is the catalogue, and it is built from nothing else.

A page links the stylesheet, sets the few sizes it wants to tune, and adds only what is genuinely its own — a stream strip's cells, a device's chrome. Page rules come after the system in the cascade, so an override is always one line in the page that needs it.

01 Colour every value below is read back out of the stylesheet

Surfaces and ink. Two surfaces only — the ground everything sits on, and the panel that lifts a region off it — separated by a one-pixel rule.

The blue ramp. --dmg-4 is the reading blue for figures, links and headings; --dmg-3 labels; the two darker steps are fills.

One accent. --hot marks the thing to act on or look at — the current tab, the focus ring, the primary button, the number carrying the point. Using it for anything else is how a page stops having a focal point.

Status, and the meaning colours: one hue per kind of thing in an encoded stream, so a cell in a strip, its swatch in a legend and its row in a table all agree.

Hardware. The emulated Franklin unit: grey-green glass in a dark case.

02 Type two faces, eight sizes

Silkscreen is a label face: eyebrows, headings, stage labels, tab names, the numeral badge on a step. It never sets running text. Everything else is IBM Plex Mono, because every page is ultimately about bytes in rows.

08 Working in it
  • Start from the tokens. A new value is a decision; if it is worth making, it is worth naming on :root where every page can see it.
  • Tune through the metric tokens — --table-max-h, --chart-h, --cell-h, --grid-aside, --marker-w — rather than repeating the rule that reads them.
  • One accent. If two things on a page are hot, neither is.
  • Keep the page's own CSS about the page. If a second page needs the same rule, it belongs here instead, and the second page is where you find that out.
  • No colour literals outside the tokens, including in generated SVG: presentation attributes take var(--hot) just as well as a hex.
  • Leave focus alone. The ring is declared once, at zero specificity; a component that needs a tighter offset says only that.

The stylesheet is design-system.css; this catalogue uses no other rules than the ones it shows. The demos it dresses: RPR1, YLK1, Verse, Search, Reader and Device.
